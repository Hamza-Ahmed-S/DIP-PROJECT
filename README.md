## 📖 Overview

A modern, interactive web application for bioinformatics analysis featuring ATP thermodynamics, DNA/protein sequence analysis, genome assembly metrics, and real-time community analytics. Built with Python and Streamlit for accessibility and ease of use.

**Perfect for:**
- 🎓 Students learning bioinformatics
- 🔬 Researchers needing quick analyses
- 👨‍🏫 Educators demonstrating concepts
- 🧬 Anyone interested in molecular biology

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| **🧪 ATP Hydrolysis** | Calculate Gibbs free energy across different tissues |
| **🧬 DNA Analysis** | GC content, ORF detection, nucleotide distribution |
| **🔬 Protein Analysis** | Amino acid frequency, hydrophobicity, transmembrane prediction |
| **🎯 Advanced Tools** | ORF finding, codon distance, DNA translation |
| **📊 N50 Calculator** | Genome assembly quality metrics |
| **📈 Analytics Dashboard** | Real-time community statistics |


```bash

# Install dependencies
pip install -r requirements.txt

# Launch application
streamlit run app.py
```

## 💻 Tech Stack

- **Frontend:** Streamlit (Python web framework)
- **Visualizations:** Plotly (interactive charts)
- **Data Processing:** Pandas
- **Core Algorithms:** Pure Python (no heavy bioinformatics libraries)

**Why this stack?**
- ✅ Fast development
- ✅ Easy deployment (free hosting)
- ✅ Minimal dependencies
- ✅ Great for prototyping

## 🎯 Use Cases

### Example 1: Analyze DNA Sequence
1. Navigate to "DNA & Protein Analysis"
2. Upload FASTA file or use sample data
3. View GC content, ORF locations, and nucleotide distribution
4. Export results

### Example 2: Calculate Genome Quality
1. Go to "N50 Calculator"
2. Input contig lengths (paste or upload)
3. Get N50/N90 metrics instantly
4. View cumulative distribution chart

### Example 3: ATP Energy Calculations
1. Open "ATP Hydrolysis Analysis"
2. Adjust tissue metabolite concentrations
3. Compare ΔG values across tissues
4. Understand cellular energetics
